# Драфт-помощник Dota 2

Подсказывает, кого пикать: мета по твоему рангу, свободные позиции, контрпики и синергия, теги (пуш, глобалки, Рошан, линия).

Теги: урон по Рошану засчитывается только керри и мидеру (позиции 1–2), глобалки и урон по башням — на любой позиции.

## Быстрый старт
Открой `index.html` двойным кликом. Мета скачается с OpenDota сама.
Контрпики и синергия появятся после подключения STRATZ (ниже).

## Как пользоваться
1. Выбери режим: «Добавить нам», «Добавить врагам» или «Забанить».
2. Начни писать имя (`пудж`, `am`, `сф`, `инвок`) и нажми Enter.
3. Если тиммейт взял героя не на его обычную позицию, нажми нужную цифру 1–5 у героя. Позиции врагов ставить не нужно: сайт считает их по статистике (можно поставить вручную, если точно знаешь).
4. Справа появятся советы на каждую свободную позицию. Нажми на героя, чтобы взять его.
5. Когда обе команды собраны по 5 героев, справа появятся «Итоги драфта»: шанс на победу, линии, ранняя игра, мид-гейм и лейт.
6. В «Настройках» выбери свой ранг и период статистики («С начала патча», 1, 3, 7, 14 или 30 дней).

## Что обновляется само
- Дата текущего патча (включая буквенные) — с официального сайта Dota 2, вручную ничего менять не нужно.
- Пока новый патч не набрал неделю игр, недостающее добирается из дней до патча; каждый день доля нового патча растёт.
- Пары и линии STRATZ: подмешивается прошлая неделя, пока текущая набрана не полностью.
- Позиции героев и «сильная линия» — из статистики STRATZ; новые герои подхватываются сами.

## Подключение STRATZ (контрпики и синергия)
1. Возьми бесплатный токен на stratz.com → API.
2. Создай репозиторий на GitHub и загрузи туда все файлы из этой папки (вместе с `.github`).
3. Settings → Secrets and variables → Actions → New repository secret: имя `STRATZ_TOKEN`, значение — токен.
4. Actions → «Обновить данные STRATZ» → Run workflow. Дальше оно запускается само каждый день.
5. Settings → Pages → Deploy from a branch → `main`, папка `/ (root)`. Через минуту сайт будет по ссылке `имя.github.io/репозиторий`.
6. Открой ссылку в Chrome или Edge → значок «Установить приложение» в адресной строке.

Если запуск в Actions упал с ошибкой GraphQL — скопируй текст ошибки, запрос поправим.

## Где что лежит
- `index.html` — приложение. Таблица позиций и тегов героев — в начале скрипта (`HERO_TABLE`), её можно править.
- `scripts/fetch-stratz.mjs` — скачивает из STRATZ в папку `data`: пары героев (`matchups-*.json`), статистику по дням за 30 дней (`daily-*.json`), винрейт по длительности матча (`time-*.json`), исходы линий (`lane-*.json`) и `diagnostics.json` — что скачалось, а что нет.
- `.github/workflows/update-stratz.yml` — ежедневный запуск скрипта.
